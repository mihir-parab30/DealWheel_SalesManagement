# DealWheel_SalesManagement

DealWheel - Vehcile Sales Management System is a hybrid data-management platform that streamlines every stage of dealership operations by fusing a **relational core in MySQL Workbench** with a **flexible MongoDB layer**. Structured business entities—customers, vehicles, branches, reservations, sales orders, warranties, and service records—reside in a fully normalized MySQL schema that guarantees transactional integrity and supports complex SQL analytics. Complementing this, MongoDB captures high-volume, semi- and unstructured data such as IoT telematics feeds, technician notes, and image attachments, enabling horizontal scalability without sacrificing agility. Exposed through RESTful micro-services and a Python analytics SDK, DealWheel equips sales, finance, and service teams with real-time dashboards, ad-hoc query capabilities, and predictive-maintenance models. By unifying inventory control, customer interactions, and post-sale support in a single data backbone, the system eliminates silos, shortens decision cycles, and delivers a 360° view that fuels revenue growth and customer loyalty for modern vehicle dealerships.

# Project Consists of:
- Conceptual Data Modelling (EER Model and UML Model)
- Mapping Conceptual Model to Relational Model
- Implementation of Relational Model: MySQL & NoSQL
- Database access via Python
- Data Visualization in Python
